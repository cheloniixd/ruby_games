# Ruby Terminal Games

## Tic Tac Toe v1

**Directions**:
   - `Run main.rb` or type `ruby ./tic_tac_toe/version_1/main.rb` in the terminal
   - `Follow the directions in the terminal`


## Tic Tac Toe v2

**Directions**:
   - `Run main.rb` or type `ruby ./tic_tac_toe/version_2_ai/main.rb` in the terminal
   - `Enter your mark; the computer takes the other one`
   - `Enter positions as 'Row Column' (0 to 2), e.g. 1 1 for the center`
